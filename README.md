# JK SOLUÇÕES EM TI - Site Institucional

Site institucional da JK SOLUÇÕES EM TI, empresa especializada em Consultoria de TI, Segurança Eletrônica, Processos Automatizados e Software de Gerenciamento.

## 🚀 Tecnologias

- **Next.js 14** - Framework React com App Router
- **TypeScript** - Tipagem estática
- **Tailwind CSS** - Estilização
- **Lucide React** - Ícones

## 📋 Pré-requisitos

- Node.js 18+ 
- npm ou yarn

## 🔧 Instalação

```bash
# Instalar dependências
npm install

# Executar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Executar build de produção
npm start
```

## 📁 Estrutura do Projeto

```
├── app/
│   ├── page.tsx          # Página inicial
│   ├── sobre/            # Página sobre
│   ├── servicos/         # Página de serviços
│   ├── contato/          # Página de contato
│   ├── projetos/         # Página de projetos
│   └── area-do-cliente/  # Área do cliente (em desenvolvimento)
├── components/
│   ├── layout/           # Header e Footer
│   ├── ui/               # Componentes UI reutilizáveis
│   └── animations/       # Animações de scroll
├── public/               # Arquivos estáticos
│   ├── robots.txt        # Configuração para crawlers
│   └── sitemap.xml       # Mapa do site
└── lib/                  # Utilitários
```

## 🌐 Deploy na Locaweb

1. Execute o build:
```bash
npm run build
```

2. A pasta `.next` será gerada com os arquivos otimizados

3. Faça upload dos arquivos para o servidor Locaweb
